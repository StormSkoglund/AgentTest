# PokéPulse Dashboard

A React + Vite dashboard that pulls live data from [PokéAPI](https://pokeapi.co/). The app lets users switch between curated Pokémon collections, search the loaded data, browse card grids, inspect a featured carousel, and review lightweight analytics.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`

## Deployment

GitHub Pages deployment is configured through `.github/workflows/deploy.yml` and uses the repository name as the Vite base path.
